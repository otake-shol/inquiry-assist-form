

## 書く言語

この依頼では、人が読む文章を{{language}}で書く。上の指示は日本語で書かれているが、出力の文章は{{language}}にする。

- 対象は、JSON の値のうち人が読む文章のすべて（質問文、選択肢、言い直した文章、要約、事実、説明、次に確認することなど）。
- JSON のキーと、識別子（id、種類やシステムの識別子）、ファイルのパスは変えない。
- 資料からの引用は訳さない。資料に書かれているとおりに、1文字も変えずに写す。
- 本人が書いた文章をそのまま入れる項目も、訳さない。
- 資料が別の言語で書かれていても、調べることをやめない。検索には、資料に書かれていそうな言葉（資料の言語の言葉）を使う。
